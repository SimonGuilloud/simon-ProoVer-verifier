## Scoring

Scoring scheme (proposal):
  * Saying a Bad proof is Bad   = +2
  * Saying a Good proof is Good = +1
  * Saying Nothing              =  0
  * Saying a Good proof is Bad  = -1
  * Saying a Bad proof is Good  = -2 (or disqualify)

For a test set with 100 good proofs 
  * Saying all proofs are Good  = +100 (maximal)
  * Saying all proofs are Bad   = -100
  * Saying nothing              =   0
  
For a test set with 50 good proofs and 50 bad proofs:
  * Saying all proofs are Good  = -50
  * Saying all proofs are Bad   = +50
  * Saying good good and bad bad= +150 (maximal)
  * saying good bad and bad good= -150 (minimal)
  * Saying nothing              =   0
  
For a test set with 100 bad proofs:
  * Saying all proofs are Good  = -200
  * Saying all proofs are Bad   = +200 (maximal)
  * Saying nothing              =   0
